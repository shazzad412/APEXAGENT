# APEX AGENT - Japan Real Estate Management System

🏠 **Fudosan (不動産) Property Management Solution for Japan**

Developer: Shazzad (Niigata, Japan)  
GitHub: @shazzad412

## 🌸 Features
- Property Listing - Bukken (物件) Management
- Admin Panel - Full CRUD
- Property Details with Image Upload
- Contact & Inquiry System
- Responsive Design
- PHP / MySQL / XAMPP

## 📁 Project Structure
- admin/ - Admin dashboard
- assets/ - CSS, JS, Images
- includes/ - DB config
- uploads/ - Property images
- index.php - Home page
- properties.php - List

## 🛠️ Tech Stack
PHP 8, MySQL, HTML5, CSS3, Bootstrap

## 🇯🇵 Made for Japan Fudosan Business
Designed for Japanese real estate agencies (不動産会社)
